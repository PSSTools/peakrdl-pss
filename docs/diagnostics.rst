Diagnostics
===========

Every diagnostic has a stable ID. Messages get reworded; IDs do not, so search
for the ID rather than the message text, and reference IDs in bug reports.

This page is generated from the exporter's diagnostic table, so it cannot
describe a check that does not exist or omit one that does.
